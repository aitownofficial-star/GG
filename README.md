# 진급 점수표

방문자는 계급·보직별 점수표를 열람할 수 있고, 관리자 로그인 후 점수 항목을 추가·수정·삭제할 수 있습니다.

## 환경변수
호스팅 서비스의 Environment 설정에 등록하세요. 실제 비밀번호를 코드나 채팅에 올리지 마세요.

- `ADMIN_USERNAME`: 관리자 아이디
- `ADMIN_PASSWORD`: 강력한 관리자 비밀번호
- `SESSION_SECRET`: 길고 무작위인 세션 비밀 문자열
- `NODE_ENV`: `production`

## 실행
`npm install` 후 `npm start`로 실행합니다.

## 중요
이 초기 버전은 점수를 `scores.json` 파일에 저장합니다. 일부 클라우드 호스팅에서는 재배포·재시작 시 파일이 사라질 수 있으므로, 실제 운영 전 영구 디스크나 PostgreSQL로 옮기는 것이 좋습니다. 세션 저장소도 단일 인스턴스용 초기 설정이므로 운영 환경에서는 영구 세션 저장소를 권장합니다.
